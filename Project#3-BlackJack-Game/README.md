# 🃏 Blackjack Game

A terminal Blackjack game built in Python. Get dealt cards, choose to hit or stand, and try to beat the dealer without going over 21.

## How to Play
1. Run `python BlackjackGame.py`
2. Type `y` to start a game.
3. You get 2 cards and see the dealer's first card.
4. Type `y` to draw another card or `n` to stand.
5. The dealer then draws until they reach 17 or more, and the higher score without going over 21 wins.
